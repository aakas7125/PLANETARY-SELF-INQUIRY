# Evidence Registry

This directory will hold canonical, inspectable claim and source records derived from approved source packages. `CLAIM_REGISTRY.json` and `SOURCE_REGISTRY.json` begin empty because the authoritative packages are absent.

Do not populate either registry from filenames, guesses, unsourced prose, or implementation constants. Integration must retain scope, boundaries, assumptions, uncertainty, limitations, and provenance. Model-specific evidence belongs under `model-specific/` once approved and imported.
