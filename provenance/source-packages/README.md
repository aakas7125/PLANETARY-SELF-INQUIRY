# Historical Source Packages

This directory stores verbatim historical specialist packages imported from prior workstreams.

Rules:

1. Never silently edit a historical source package. Preserve the received file and its identity.
2. Record integrated and current truth in `/contracts`, not by rewriting provenance.
3. Keep historical disagreement visible. Record conflicts and reconciliations in `/contracts/INTEGRATION_NOTES.md`.
4. Add provenance metadata or checksums alongside a package without altering the package itself.
5. Do not infer package contents from a filename or reconstruct an absent package from memory.

No specialist source packages were present at bootstrap.
