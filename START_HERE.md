## Learning note — “unknown” is not “zero”

The old Ledger goods slider turned an undefined 0–10 rating into numerical emissions and land effects. Suspending that unsupported calculation removes a misleading estimate; it **does not** establish zero goods impact. The correct statement is that goods impact is **outside the current quantified subtotal**. See the [bounded disposition](project-state/LEDGER_GOODS_DISPOSITION_PROPOSAL_2026-10-17.md). This is the difference between improving a model's honesty and claiming the world has changed.

## How the workflow actually works

1. **You — Owner:** Set direction, approve major scientific/product/ethical choices, and personally arrange optional participant invitations. Your thesis and HiWi capacity also matters.
2. **Vision Manager Advisor (this chat):** Clarifies strategy, challenges priorities and explains choices; it is **not** a second autonomous Project HQ.
3. **PSI HQ:** Reads fresh repository state; finds and publishes the smallest authorized tasks; independently reviews exact PR heads, tests and limitations; accepts/merges qualifying work; reconciles the queue and updates this page. **Execute within delegated authority by default, escalate only real Owner decisions.**
4. **Research & Evidence:** Checks scientific claims, units, boundaries, calibration and provenance; a research report is **not** automatic permission to adopt a new metric.
5. **AP Framework & Corpus:** Checks philosophical attribution and inquiry integrity. Keep **science, Acharya Prashant material and PSI's Project Interpretation** separate.
6. **Cursor normally, Local Codex selectively:** Implement only properly authorized GitHub Issues and return reviewable evidence. They never self-merge. [Capacity rule D-024](project-state/DECISIONS.md#d-024--temporary-capacity-aware-executor-selection) protects GPT capacity for HiWi, thesis and HQ.
7. **HQ again:** Reviews the returned work and continues the authorized chain instead of ending with a status report.

**How information crosses chats:** GitHub is the shared record, **not an automatic message to an inactive chat**. A workstream must read its current Issues; Cursor also has a specific `[CURSOR-DISPATCH]` wake mechanism. A chat suggestion alone is not executable authority. See the [control plane](project-state/UNIVERSAL_ISSUE_CONTROL_PLANE.md).

**Owner shortcut:** **CGCAW** means *Check GitHub and Continue Authorized Work*: fresh intake **and** actual work, not merely a status summary. For a known PR, ask “Check PSI PR #…” for a smaller targeted review.

### Translation of repository terms

| Term | What it means |
| --- | --- |
| **Issue** | Task, feedback or decision record. An open Issue is not necessarily an executable task. |
| **PR / exact head** | Proposed change and the exact version HQ reviews. A published PR is not accepted work. |
| **Merged into `main`** | Accepted repository state, **not** proof of live deployment. |
| **Research/AP proposal** | Qualified domain evidence, **not** automatic product or philosophical adoption. |
| **Prototype** | Comparison artifact, **not** approved public behavior. |
