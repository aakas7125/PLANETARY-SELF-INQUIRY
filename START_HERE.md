## Learning note — “unknown” is not “zero”

The former goods slider turned an undefined 0–10 judgment into emissions, land and narrative outputs. [Suspending it](project-state/LEDGER_GOODS_DISPOSITION_PROPOSAL_2026-10-17.md) removes a number that lacked a usable definition. Goods still have impacts; PSI currently leaves them **outside its quantified subtotal**. This is a model-coverage statement, not a finding of zero impact. When reading any result, ask: *Which inputs are counted, and which are still unknown?*

## How the workflow works

1. **You, the Owner:** Set direction and make reserved product, ethical, scientific-adoption and resource decisions.
2. **Project HQ:** Checks current repository evidence; authorizes the smallest bounded work within delegated authority; independently reviews returned PR heads, validation and limits; accepts qualifying work and continues the queue.
3. **Research & Evidence:** Tests empirical claims, units, calibration and sources. A report does not itself adopt a new metric.
4. **AP Framework & Corpus:** Checks attribution and philosophical integrity. Science, AP material and PSI Project Interpretation stay distinct.
5. **Cursor normally, Local Codex selectively:** Implement only authorized bounded tasks and return evidence. They do not self-merge. The [temporary capacity preference](project-state/DECISIONS.md#d-024--temporary-capacity-aware-executor-selection) preserves GPT capacity for thesis, HiWi and HQ.
6. **HQ again:** Reviews, reconciles and continues justified work. A completed PR is a checkpoint, not a reason to stop.

GitHub is the shared record, **not a message automatically delivered to a dormant chat**. A workstream reads its Issues when active; Cursor has a specific dispatch protocol. See the [control plane](project-state/UNIVERSAL_ISSUE_CONTROL_PLANE.md). **CGCAW** means *Check GitHub and Continue Authorized Work*; for one known PR, request a targeted PR review.

| Repository term | Meaning |
| --- | --- |
| **Issue** | Task, feedback or decision record; an open Issue is not necessarily executable. |
| **PR / exact head** | Proposed change and its specific reviewed version; publication is not acceptance. |
| **Merged into `main`** | Accepted repository state; not proof of deployment or human understanding. |
| **Specialist report** | Qualified Research/AP finding; not automatic product adoption. |
| **Prototype** | Comparison artifact; not approved public behavior. |
| **CI / synthetic check** | Repeatable technical evidence; not a human comprehension study. |
