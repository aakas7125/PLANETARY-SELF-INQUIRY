# Decision Log

## D-001 — Preserve V17 as reference baseline

- Decision: V17 is the accepted, frozen reference baseline.
- Consequence: changes must not be described as V17 or applied to its reference tag after that tag can be safely established.

## D-002 — Govern future development locally

- Decision: future development becomes repository-backed and governed by the constitution, contracts, provenance, state, and regression records.
- Consequence: cloud conversation state alone is not canonical current project state.

## D-003 — Treat generated and external implementations as candidates

- Decision: generated or externally produced implementations, including Antigravity material, are candidate material only.
- Consequence: their existence does not authorize integration or make them canonical.

## D-004 — Gate external code integration

- Decision: external code must pass the project constitution, applicable contracts, and regression checks before integration.
- Consequence: unresolved conflicts remain visible in integration notes and block acceptance where material.
